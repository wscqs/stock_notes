# 交易历史盈亏折线图设计

## 目标
在股票编辑页与交易列表的交易 cell 增加趋势入口，以底部弹窗展示该笔交易自开仓以来的每日累计浮动盈亏、最大回撤，并支持收益额和收益率切换。帮助用户直观看到曾经盈利及从高点回吐的幅度。

## 已确认口径
- 买入交易每日盈亏：`(当日价 - 开仓基准价) × 开仓股数`；卖出交易取相反方向。
- 收益率以开仓金额为分母，金额和收益率切换只改变单位，不改变曲线形状。
- 最大回撤：`max(历史每日盈亏, 0) - 最新盈亏`，全程亏损为 0，始终相对最新点，不随触摸历史点改变。
- 未平仓更新至最近交易日；完整平仓且填写平仓日期后固定至平仓日，最后一个点用实际平仓价计算，与 cell 收益一致。
- 默认使用腾讯前复权行情，开仓基准取开仓日的前复权收盘价；已平仓以平仓日为复权截止日。界面标注“前复权估算，不含交易费用”。港股接口无前复权数据时使用不复权并明确标注。
- 不支持的美股、北交所等市场明确提示，不生成假数据；金额不做汇率换算。

## UI 与状态
- 交易 cell 开仓信息行增加小型趋势图标按钮，有足够点击区域，不与编辑、删除和整卡点击冲突。
- 底部弹窗含关闭按钮、收益率/收益额页签、日期、当前盈亏、最大回撤、单序列折线和 0 轴。
- 使用 fl_chart 1.3.0：2px 折线，正收益红色、负收益绿色及对应浅色渐变面积，细分网格适配明暗主题；只标注必要日期，触摸时显示十字参考线和该日数值。
- 加载中、网络失败可重试、无数据、缺少平仓日期提示均有独立状态；平仓日期在弹窗中可直接补填并保存。
- 使用中英双语 TextKey，跟随应用主题。

## 数据与接口
- `StockTrades` 新增可空 `closeDate`，Drift schema 13 升至 14；已有数据为 null。
- 交易编辑弹窗在完整平仓时显示平仓日期，校验不早于开仓日且不晚于当天；非完整平仓不保存该字段。
- 新增独立历史行情服务：复用股票代码格式化规则，请求 `web.ifzq.gtimg.cn/appstock/app/fqkline/get`。
- A 股用 `qfq` 和 `qfqday`；港股用空复权参数和 `day`；解析 `[date, open, close, high, low, volume]`，按日期排序、去重。
- 接口可能返回 640/641 条并截掉最早数据，所以按时间窗口向前分段，直到开仓日；对请求次数、未来日期和空响应做防护。
- 内存缓存当前运行期间的行情键（市场、代码、复权截止日）；不做长期缓存前复权数据，避免除权后旧结果污染曲线。

## 边界与非目标
- 开仓日为非交易日时以区间内首个交易日为基准；无区间行情则无数据。
- 股数、开仓价非法或为零时禁用图表入口；部分平仓按未平仓和开仓股数展示。
- 历史已平仓但没有平仓日期时，先按最近交易日展示并明确提示，可补填日期后重新加载固定结果。
- 不记录每日收益表，不新增后台，不计算手续费、税费、现金分红到账和汇率，不实现历史账户总资产。
- 除权行情只能提供复权估算，不能替代券商真实账户收益。

## 验证
纯函数覆盖多空方向、全程亏损、正收益后回吐、基准价和非交易日；接口覆盖 A 股/港股键、异常响应和分页；数据库覆盖 v13→v14；widget 覆盖日期输入、图标入口、加载失败、页签与图表数值。最后运行格式化、定向测试、`flutter analyze` 和项目测试集（排除已记录的既有挂起/失败测试）。
